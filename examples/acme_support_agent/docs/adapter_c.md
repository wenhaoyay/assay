# Adapter C (65 W USB-C power adapter)

Adapter C is a 65 W USB-C power adapter with a 1.5 m cable.

## Compatibility
Adapter C works with Device Alpha, Device Gamma and Device Beta. Device Beta charges at its normal 15 W maximum when connected to Adapter C.

Adapter C is not compatible with Device Alpha Classic, which has a micro-USB port.

## Warranty
Accessories, including Adapter C, have a 12-month warranty.
