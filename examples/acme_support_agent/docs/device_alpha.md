# Device Alpha (model A100)

Device Alpha is Acme's wireless home hub, model A100, released in 2023. It connects up to 32 paired smart-home devices over Wi-Fi 6 and Bluetooth 5.2.

## Power
Device Alpha is powered through its USB-C port and needs a 45 W (or higher) USB-C power adapter. Adapter C (65 W) is the recommended adapter.

## Warranty
Device Alpha comes with a 24-month standard warranty from the date of purchase.

## Operating conditions
Use Device Alpha at temperatures between 0 °C and 40 °C. It is for indoor use only.

## Firmware
The current Device Alpha firmware is version 3.2, released in October 2025.
