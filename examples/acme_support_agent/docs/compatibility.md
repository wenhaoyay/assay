# Compatibility overview

| Product | Adapter C | Adapter D | Mount Kit M1 |
|---|---|---|---|
| Device Alpha (A100) | Yes | No | No |
| Device Alpha Classic (A050) | No | Yes | No |
| Device Beta (B200) | Yes | No | No |
| Device Gamma (G300) | Yes | No | Yes |

Device Alpha can control Device Gamma and Device Beta once they are paired in the Acme Home app.
Device Beta Pro (B250) ships with its own charger; Adapter C also works with it.
