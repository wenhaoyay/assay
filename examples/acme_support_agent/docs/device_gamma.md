# Device Gamma (model G300)

Device Gamma is Acme's 10.1-inch smart display, model G300.

## Power
Device Gamma needs a 65 W USB-C power adapter. Adapter C is the supported adapter; lower-wattage adapters cause the screen to dim and the display may restart.

## Mounting
Device Gamma can stand on a desk or be wall-mounted with Mount Kit M1.

## Warranty
Device Gamma comes with a 24-month standard warranty.
