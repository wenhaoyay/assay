# Device Alpha Classic (model A050) - discontinued

Device Alpha Classic, model A050, was the first-generation Acme home hub. It was discontinued in 2022 and replaced by Device Alpha (A100).

## Power
Alpha Classic uses a micro-USB port and the 18 W Adapter D.

## Warranty
Alpha Classic units were sold with a 12-month warranty. Acme no longer sells Alpha Classic, but existing units can still be repaired for a fee.

## Pairing
Alpha Classic pairs with up to 16 devices.
